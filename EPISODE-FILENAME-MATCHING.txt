Episode filename matching - Titlovi.com.Unified 1.1.9
======================================================

This note documents the Common engine rules used when a downloaded archive
contains several possible subtitle files for an episode.

Selection priority for a normal single-episode video:

1. Explicit season + episode (S01E01, 1x01, etc.).
2. Legacy individual forms with separated tokens or Roman season numbers.
3. Episode-only numbering (E01, Part 1, 01, 001).
4. Episode-title fallback.
5. A sole subtitle file, only when it is not explicitly a multi-episode bundle.

Examples of supported legacy individual forms:

  BlackAdder_I_01                              -> S1E1
  BlackAdder_II_03                             -> S2E3
  BlackAdder_IV_06                             -> S4E6
  season_01_blackadder_season_01_episode_01   -> S1E1

Examples of multi-episode bundles:

  The Black Adder Ep 1,2,3-Srp.sub  -> E1-E3 bundle
  BlackAdder_I_123_ser.sub          -> S1 E1-E3 bundle
  BlackAdder_I_456_ser.sub          -> S1 E4-E6 bundle

Important safety rule:

A subtitle that explicitly represents several episodes is not treated as a
valid subtitle for an ordinary single-episode file. A grouped subtitle is only
considered when the host request itself reports an exact multi-episode range.
For example, an E01-E03 video may use an E1,2,3 bundle, while an E01 video may
not.

Whole-season/whole-series archives and nested ZIPs are inspected using the same
rules. The engine attempts to select the exact requested season/episode rather
than accepting the first subtitle file found in an archive.
