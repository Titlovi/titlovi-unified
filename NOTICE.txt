Titlovi.com.Unified

This is the canonical Titlovi.com Unified source repository in the official
Titlovi GitHub organization. The imported development code still identifies
its Emby and Jellyfin plugins as "Titlovi.com (Unofficial)" until an approved
official release updates their metadata. No official Unified 2.0 release has
been published merely by importing the source.
