Titlovi.com.Unified

This is the canonical Titlovi.com Unified source repository in the official
Titlovi GitHub organization. The Emby and Jellyfin plugin metadata uses the name
"Titlovi.com" and version 2.0.0.0, from the canonical source tag v2.0.0.
The Emby Server 4.10.x plugin was first published on 2026-10-20 at
https://github.com/Titlovi/titlovi-emby/releases/tag/v2.0.0.
The Jellyfin 12 plugin was published on 2026-10-20 at
https://github.com/Titlovi/titlovi-jellyfin/releases/tag/v2.0.0.
It is available through the existing Jellyfin plugin catalogue, which retains
all nine earlier Jellyfin 1.x release entries. Current catalogue developer
credit is "mihvel"; Matko's original contributions remain acknowledged below.
