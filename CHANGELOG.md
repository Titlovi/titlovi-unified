# Changelog

This document records **official Titlovi.com Unified releases** from version 2.0.0.0 onward.

## Unreleased — 2.0.0.0 (in preparation)

The first official Unified release **has not been published**. Its planned distribution targets are:

- **Jellyfin 12 / .NET 10**, using the existing official [Titlovi.com Jellyfin repository](https://github.com/Titlovi/titlovi-jellyfin) and catalogue.
- **Emby Server 4.10.x**, distributed as a manually installed `Emby.Titlovi.dll` from the [Emby repository](https://github.com/Titlovi/titlovi-emby).

The two host plugins are built from the same source code, with shared logic compiled directly into each host assembly. The final 2.0.0.0 release notes, compatibility claims and distribution links will be finalized when the official packages have been approved and published.

Earlier **pre-official development history** is preserved in [the maintainer archive](docs/maintainers/archive/CHANGELOG-PRE-OFFICIAL.md) and the Git commit history. Those experimental releases are not part of the official Unified 2.0 release series.
