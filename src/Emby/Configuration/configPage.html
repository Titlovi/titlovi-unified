Titlovi.com

Titlovi.com subtitle provider for Emby. Uses your own Titlovi.com account and API access.

When the language selected in Emby is Serbian, Croatian or Bosnian, the plugin also searches the other two languages. Results are grouped with the selected language first. This option is ignored for all other languages.

Accepted subtitle formats

Choose which subtitle file formats the plugin may extract and return from Titlovi.com archives. At least one format must remain enabled.
If enabled, non-UTF-8 subtitle files are detected and converted to UTF-8 before Emby saves them.
When enabled, the plugin writes detailed search, API, download, ZIP-selection and encoding diagnostics to emby-titlovi-debug.log. The lightweight emby-titlovi.log remains active either way. Passwords and API tokens are never written to either log. The debug log can contain media titles and subtitle filenames.

The token is obtained automatically on the first subtitle search and cached by the plugin.
